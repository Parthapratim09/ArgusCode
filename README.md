# ArgusCode - Real-Time Collaborative Coding Platform

live link https://arguscode.onrender.com

## 🚀 About ArgusCode

**ArgusCode** is a real-time collaborative coding platform that enables developers to code together, communicate, and manage projects efficiently in a shared environment.

The platform allows multiple users to collaborate on code simultaneously with role-based access control, multi-language code execution, authentication, and cloud deployment support.

---

# 🧠 Why the Name "ArgusCode"?

In Greek mythology, **Argus Panoptes** was a giant with a hundred eyes.

The name **ArgusCode** symbolizes:

* Multiple developers reviewing code together
* Better bug detection
* Enhanced code quality
* Continuous monitoring and collaboration

Just like Argus watched everything with many eyes, ArgusCode represents many developers collaborating and improving code together.

# ⚙️ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/your-username/ArgusCode.git
```

## Navigate to Project

```bash
cd ArgusCode
```

## Install Frontend Dependencies

```bash
cd client
npm install
```

## Install Backend Dependencies

```bash
cd ../server
npm install
```

# ▶️ Run Project

## Start Backend Server

```bash
npm run server
```

## Start Frontend

```bash
npm start
```

---

# 🔐 Environment Variables

Create a `.env` file in the server directory.

```env
PORT=4000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
EMAIL_USER=your_email
EMAIL_PASS=your_email_password
```
